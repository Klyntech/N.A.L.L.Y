# Creative

Unified skill for business/content writing and creative thinking.

## Phase 1: Understand the Goal

- What's the purpose? (inform, persuade, sell, summarize)
- Who's the audience? (executive, developer, customer, investor)
- What tone? (professional, casual, urgent, friendly)
- What format? (email, blog post, landing page, meeting notes)

## Phase 2: Choose Content Type

### Email
Structure:
1. **Subject line** — specific, action-oriented, no spam triggers
2. **Greeting** — match relationship (Hi/Hey/Dear)
3. **Context** — why you're writing (1-2 sentences)
4. **Ask** — what you need from them (clear, specific)
5. **Details** — background info (only what's needed)
6. **Closing** — next steps, timeline, thanks
7. **Signature** — name, title

Rules:
- One email = one ask
- Put the ask in the first 3 sentences
- Use short paragraphs (2-3 sentences max)
- No walls of text

### Landing Page
Structure:
1. **Hero** — headline + subheadline + CTA
2. **Problem** — what pain point do they have?
3. **Solution** — how your product solves it
4. **Features** — 3-5 key features with icons
5. **Social proof** — testimonials, logos, stats
6. **FAQ** — address objections
7. **Final CTA** — repeat the call to action

Headline formulas:
- "[Result] without [Pain Point]" — "Ship faster without breaking things"
- "The [Adjective] way to [Goal]" — "The smarter way to manage your team"
- "Stop [Problem], Start [Solution]" — "Stop guessing, start measuring"

### Product Description
- Lead with the benefit, not the feature
- Use sensory language (feel, see, experience)
- Include specific numbers ("saves 3 hours/week" not "saves time")
- Address the #1 objection

### Meeting Notes
Structure:
1. **Date + Attendees** — who was there
2. **Agenda** — what was discussed (one line per topic)
3. **Decisions Made** — what was agreed (numbered list)
4. **Action Items** — who does what by when (table format)
5. **Parking Lot** — topics deferred to next meeting

Action item format:
| Who | What | By When |
|-----|------|---------|
| Clinton | Deploy v2.0 to staging | Friday |
| Team | Review PR #42 | Monday |

### Brainstorming
Structure:
1. **Frame the problem** — one sentence, specific
2. **Diverge** — generate 10+ ideas, no judgment
3. **Converge** — group similar ideas, score by impact/effort
4. **Pick top 3** — most promising, with next steps

Rules for brainstorming:
- Quantity over quality initially
- Defer judgment — no "that won't work" during diverge
- Build on others' ideas ("yes, and...")
- Use "How might we..." to reframe problems

## Phase 3: Write

### Copywriting Formulas
- **AIDA**: Attention → Interest → Desire → Action
- **PAS**: Problem → Agitate → Solution
- **Before-After-Bridge**: Current state → Desired state → How to get there

### Tone Matching
| Context | Tone | Example |
|---------|------|---------|
| Investor email | Confident, specific | "We've grown 40% MoM for 3 months" |
| Bug report to team | Direct, actionable | "Found: search returns empty for 2+ word queries" |
| Customer support | Empathetic, helpful | "I understand how frustrating that must be" |
| Landing page | Bold, benefit-focused | "Stop wasting time on manual data entry" |

### Formatting
- Use bullet points for lists of 3+ items
- Bold key phrases for skimmers
- One idea per paragraph
- Short sentences (15-20 words max)

## Guidelines
- Write for the reader, not yourself
- Cut every word that doesn't add value
- When in doubt, be more specific
- Read it aloud — if it sounds wrong, rewrite it
